# Pugemon для MkDocs Material

Тема документации в цветах дизайн-системы Pugemon: Gruvbox, бирюза для ссылок и фирменный жёлтый. Тёмная схема основная, светлая включается переключателем или по настройке системы.

## Что внутри

```
mkdocs.yml                     пример конфига: схемы, шрифты, расширения
requirements.txt               версия mkdocs-material, на которой тема проверена
docs/stylesheets/pugemon.css   сама тема
docs/assets/logo.png           пиксельный знак для шапки (256×256)
docs/assets/favicon.png        фавикон 32×32, уменьшен без сглаживания
docs/assets/favicon-64.png     запасной фавикон 64×64
overrides/404.html             страница 404 в чёрно-белом «режиме кино»
docs/*.md                      демо-страницы, их можно удалить
```

## Подключение к проекту

1. Скопируйте `docs/stylesheets/`, `docs/assets/` и `overrides/` в свой проект.
2. Перенесите из `mkdocs.yml` блоки `theme`, `extra_css` и `markdown_extensions`.
3. Установите зависимости и запустите:

```console
$ pip install -r requirements.txt
$ mkdocs serve
```

Схемы называются `pugemon-dark` и `pugemon-light`. Если нужна только тёмная тема, оставьте в `palette` одну запись без `media` и `toggle`.

## Что перекрашено

- Шапка, вкладки, боковое меню: активный пункт жёлтый, наведение бирюзовое.
- Код: ключевые слова и промпт `$` медные, строки и типы жёлтые, функции бирюзовые, числа розовые, комментарии приглушённые. Проверено на Python, C++ и Go.
- Заголовок блока кода (`title="main.go"`) оформлен как шапка окна.
- Примечания: note и info бирюзовые, tip зелёный, warning жёлтый, danger красный, example медный.
- Таблицы, кнопки `.md-button` и `.md-button--primary`, клавиши `++ctrl++`, выделение `==текст==`.
- Справка mkdocstrings: имена объектов бирюзовые, метки медные.

## Свои метки статуса

```html
<span class="pg-tag pg-tag--ok">готово</span>
<span class="pg-tag pg-tag--wip">в работе</span>
<span class="pg-tag pg-tag--bad">заброшен</span>
```

Для пиксель-арта на страницах добавьте картинке класс: `![спрайт](sprite.png){ .pixel }`.

## API-справка по языкам

- **Python** — `mkdocstrings[python]`, стили темы для него уже есть.
- **C++** — обычно Doxygen плюс плагин, который превращает его XML в страницы MkDocs (например, MkDoxy).
- **Go** — генератор Markdown из godoc (например, gomarkdoc), результат кладётся в `docs/`.

Плагины для C++ и Go сторонние, их стоит проверить на своём проекте перед тем, как закладываться на них.

## Примечание о версиях

Тема проверена на mkdocs-material 9.7.7, сборка `mkdocs build --strict` проходит без ошибок. При сборке Material показывает объявление о будущем MkDocs 2.0. Пока зафиксируйте версию из `requirements.txt` и обновляйтесь осознанно.
